Cara Order

Pesan kebutuhan digital printing di CALSPRINT dengan mudah melalui WhatsApp

Konsultasi kebutuhan untuk cetak sampai proses produksi dan pengiriman, kami dengan senang hati akan membantu Anda.

1

Tanyakan Kebutuhan Cetak

Sampaikan kebutuhan cetak Anda kepada admin CALSPRINT melalui WhatsApp.

Informasikan detail seperti:
  • Produk yang ingin dicetak
  • Jumlah pesanan (QTY)
  • Ukuran produk
  • Bahan yang digunakan
  • Spesifikasi & finishing
  • Deadline / kebutuhan tanggal selesai
Belum tahu spesifikasi yang cocok? Tidak masalah. Admin kami dapat membantu memberikan rekomendasi sesuai kebutuhan Anda.
2

Kirim File ke WhatsApp

Silahkan kirim file desain yang akan dicetak melalui WhatsApp kepada admin CALSPRINT.

  • Pastikan file yang dikirim sudah final dan tidak ada perubahan
  • Pastikan ukuran dan desain sudah sesuai
  • Sertakan file pendukung jika diperlukan
Jika desain dibuat menggunakan AI, pastikan rasio desain sudah sesuai dengan ukuran barang jadi. File hasil AI umumnya berupa PNG, sehingga rasio desain tidak dapat kami ubah tanpa berisiko membuat desain terlihat gepeng atau tidak proporsional.

Admin CALSPRINT akan membantu periksa file Anda sebelum diproses ke tahap berikutnya.

Untuk hasil cetak terbaik, pastikan file tidak blur atau pecah. Jika mengirim file PNG/JPG, gunakan gambar dengan resolusi yang cukup tinggi agar hasil cetak tetap tajam dan jelas.

3

Admin Memeriksa File

Admin akan mengecek file yang Anda kirim sebelum masuk ke tahap selanjutnya, untuk memastikan file dapat diproses sesuai dengan kebutuhan cetak.

Pengecekan meliputi:
  • Ukuran file
  • Rasio file
  • Kualitas gambar file
  • Kesesuaian file dengan produk yang dipesan

Jika terdapat hal yang perlu diperbaiki atau disesuaikan, admin akan menginfokannya terlebih dahulu untuk memastikan hasil cetak terbaik.

4

Konfirmasi Pesanan & Biaya

Setelah kebutuhan dan file sudah sesuai, admin akan mengonfirmasi detail pesanan Anda.

Informasi yang akan dikonfirmasi meliputi:
  • Spesifikasi pesanan
  • Estimasi waktu pengerjaan
  • Opsi pengiriman
  • Biaya produksi
  • Biaya pengiriman jika ada

Setelah semua detail sesuai, pesanan dapat dilanjutkan ke tahap pembayaran.

5

Lakukan Pembayaran

Admin akan memberikan detail pembayaran resmi CALSPRINT.

Silahkan lakukan pembayaran sesuai nominal yang telah dikonfirmasi.

Setelah pembayaran dilakukan, kirimkan bukti pembayaran kepada admin untuk dikonfirmasi.

6

Approval Sebelum Cetak

Setelah pembayaran dikonfirmasi, kami akan menyiapkan approval artwork atau preview berdasarkan file yang telah dikonfirmasi.

Tahap ini dilakukan untuk memastikan tidak ada kesalahan sebelum proses cetak, seperti:
  • Layout desain
  • Ukuran
  • Rasio desain
  • Spesifikasi lainnya
7

ACC Artwork Sebelum Produksi

Periksa kembali approval yang diberikan oleh admin sebelum memberikan ACC.

Pastikan:
  • Desain sudah benar
  • Ukuran sudah sesuai
  • Posisi desain sudah sesuai
  • Jumlah dan spesifikasi sudah benar
  • Tidak ada informasi yang ingin diubah

Jika sudah sesuai, berikan ACC. Setelah artwork mendapatkan ACC, pesanan akan dilanjutkan ke proses produksi. Pastikan seluruh detail sudah diperiksa dengan teliti.

8

Pesanan Masuk Produksi

Setelah artwork mendapatkan ACC, pesanan akan diproses oleh tim produksi CALSPRINT sesuai dengan spesifikasi yang telah disepakati.

9

Pesanan Siap Dikirim atau Diambil

Setelah proses produksi selesai, admin akan menginformasikan bahwa pesanan sudah jadi dan siap diambil atau dikirim.

Pesanan dapat:
  • Dikirim ke alamat yang telah dikonfirmasi di awal.
  • Diambil langsung di lokasi CALSPRINT.
10

Sampaikan Feedback Anda

Kami sangat terbuka terhadap feedback dari customer.

Jika terdapat kesalahan produksi yang berasal dari pihak CALSPRINT, silahkan segera informasikan kepada kami agar dapat kami periksa dan tindak lanjuti.

Jika kesalahan terbukti berasal dari pihak kami, CALSPRINT bersedia memberikan solusi dan melakukan penggantian sesuai dengan kondisi pesanan.

Bantuan & Konsultasi

Masih bingung menentukan bahan, ukuran, finishing, atau jumlah cetak? Jangan ragu untuk konsultasi dengan admin CALSPRINT. Kami dengan senang hati akan membantu Anda menemukan pilihan yang sesuai dengan kebutuhan cetak Anda.
